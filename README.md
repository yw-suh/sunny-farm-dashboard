# 햇살가득 농장 대시보드 (Sunny Farm Dashboard)

경북 영천 천도복숭아 노지 재배 농가를 위한 직관적이고 쉬운 영농 관리 대시보드 웹 애플리케이션입니다.

## 주요 화면 구성
1. **요약 카드 4개**: 총 매출(원), 총 판매 박스 수(박스), 박스당 평균 단가(원), 평균 고객 후기 평점(4.0점)
2. **판매 현황**: 공판장, 농협, 직거래, 온라인 쇼핑몰 채널별 매출 비교 막대 차트, 매출 비중 도넛 차트, 날짜별 매출 추이 선 차트 (채널 필터 실시간 연동)
3. **방제 일지**: 농약 안전사용 필수 주의 문구, 병해충별 방제 횟수 막대 차트, 방제일지 상세 표 (검색 및 필터링 기능)
4. **작업 현황**: 작업별(수확, 봉지씌우기, 적과, 전정, 방제) 총 투입 시간 막대 차트 (시간 = 인원 × 작업 시간), 월별(1~6월) 작업 일수 요약
5. **고객 후기**: 평점별(5~1점) 건수 막대 차트, 피드백 구분(장점, 불만, 개선 요청, 기타) 비율 도넛 차트, 최신순 후기 카드 목록

## 설치 및 실행 방법

컴퓨터에 Node.js (버전 18 이상 권장)가 설치되어 있어야 합니다.

1. 압축 해제 후 해당 폴더로 터미널(명령 프롬프트) 이동:
```bash
cd sunny_farm_dashboard
```

2. 패키지 설치:
```bash
npm install
```

3. 로컬 개발 서버 실행:
```bash
npm run dev
```

4. 웹 브라우저에서 `http://localhost:3000` 접속하여 대시보드를 확인합니다.

5. 배포용 빌드:
```bash
npm run build
```

## Vercel로 무료 배포하는 방법

이 프로젝트는 Vite + React SPA 기반이므로 Vercel에서 설정 없이 1분 만에 무료 배포할 수 있습니다.

### 방법 1: GitHub 연동 배포 (가장 추천)
1. GitHub(github.com)에 로그인 후 새 저장소(New Repository)를 만듭니다.
2. 다운로드받은 코드를 해당 저장소에 업로드(push)합니다.
3. [Vercel](https://vercel.com)에 접속하여 GitHub 계정으로 로그인합니다.
4. `Add New...` > `Project`를 누르고 방금 올린 저장소를 `Import`합니다.
5. 설정(Framework: Vite, Build: `npm run build`, Output: `dist`)이 자동으로 잡히므로, **`Deploy`** 버튼만 누르면 1분 뒤 고유한 무료 웹 주소(예: `sunny-farm.vercel.app`)가 생성됩니다.

### 방법 2: Vercel CLI로 바로 배포
1. 터미널에서 다음 명령어로 Vercel 도구를 설치하고 배포합니다:
```bash
npm install -g vercel
vercel
```
2. 화면의 질문에 엔터(기본값)를 몇 번 누르면 즉시 배포 URL이 발급됩니다.
